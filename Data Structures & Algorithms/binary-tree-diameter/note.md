### Task:
The diameter of a binary tree is defined as the length of the longest path between any two nodes within the tree. The path does not necessarily have to pass through the root.
We need to find the diameter of given tree.  
### Intuition:
longest path through a node = height(left subtree) + height(right subtree) of the node.

We need to find longest path through every node because any node can contains the diameter.
